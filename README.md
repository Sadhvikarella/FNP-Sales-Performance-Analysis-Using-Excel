📊 FNP Sales Performance Analysis Using Excel
An end-to-end sales data analysis project for Ferns N Petals (FNP) — a leading gifting brand in India. This project analyzes sales trends, regional performance, product categories, and customer order behavior using Excel pivot tables, charts, and an interactive dashboard.

🔍 Project Overview
The goal of this project is to answer key business questions:

Which months and occasions drive the highest sales?
Which product categories generate the most revenue?
Which cities and regions have the highest order volumes?
What is the average order value and delivery time trend?

📈 Key Insights

🗓️ Peak Sales Months: February (Valentine's Day) and August–September (Raksha Bandhan, Diwali)
🎁 Top Category: Soft Toys and Sweets drive highest order volumes
🏙️ Top Cities: Metro cities contribute 60%+ of total revenue
💰 Average Order Value: ₹3,500 – ₹4,200 across categories
🚚 Avg Delivery Time: 5–6 days, with spikes during festive seasons


📋 Analysis Performed

Revenue Trend Analysis — Monthly revenue comparison across FY
Category-wise Performance — Which product types sell the most
City-wise Order Distribution — Top performing cities by order count
Occasion-based Sales — Revenue split by gifting occasion
Top Products — Best-selling individual products by revenue
Order vs Delivery Time — Identifying fulfilment patterns
